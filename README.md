# Machine Failure Prediction

## Project Description
This project predicts whether a manufacturing
machine will operate normally or experience failure
using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Dataset
AI4I 2020 Predictive Maintenance Dataset.

## Machine Learning
A classification model is trained to predict
machine failure using sensor data.

## Features
- Air Temperature
- Process Temperature
- Rotational Speed
- Torque
- Tool Wear

## How to Run
1. Install the required libraries.
2. Run train_model.py.
3. Run predict.py.
